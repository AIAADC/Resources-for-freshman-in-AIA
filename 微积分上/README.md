# ➗ 微积分（上）

> 极限、导数、积分，  
> 一开始像高墙，  
> 但顺着概念、题型和真题走，也能慢慢拆开。

## 资料导航

- [2025微积分模拟考试](./2025微积分模拟考试)：模拟试题与答案

- `18-19答案.pdf` 至 `24-25微积分期末答案.pdf`：部分历年答案
- [期中考试复习专题讲座.pdf](./期中考试复习专题讲座.pdf)：期中专题复习

- [微积分上期中专题复习.pdf](./微积分上期中专题复习.pdf)：期中专题资料

## 使用建议

1. 复习时先把极限、导数、积分的基本题型分开整理。
2. 做真题时建议按年份成套练习，再回头补薄弱章节。
3. 考前优先看专题复习和知识点串讲，再用模拟题检验。
