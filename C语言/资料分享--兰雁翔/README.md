## 👋 这份资料怎么用？

本目录由 **兰雁翔分享**，收录 C语言课程学习与复习资料，并包含从 C 到 C++、类与对象、继承与多态等拓展课件。适合随课学习、专题补漏和期末复习时按需查找。

| 你现在的需求 | 建议从这里开始 |
| :--- | :--- |
| 刚开始学，希望按章节建立基础 | [章节课件](#slides)，从第1章依次学习 |
| 对数组、指针、字符串比较困惑 | 第5—7章课件，搭配 [指针专题](./C%E8%AF%AD%E8%A8%80%20%E6%8C%87%E9%92%88.pdf) |
| 想整理重点、回顾容易出错的地方 | [复习资料与专题笔记](#review) |
| 想做整卷练习、核对参考答案 | [历年试题导航](#exams) |
| 正在学习 C++ 入门内容 | 第11—13章课件，按本学期课程要求选用 |

> 试题按原文件中的“年级、学期、卷别”标注；年级不等同于考试发生年份。各届教学和考试范围可能不同，复习时以本学期课程要求为准。

### 做题建议

1. **先独立完成，再查看答案。** 整卷练习时，按自己的课程考试时长计时。
2. **保留解题过程。** 对程序输出题逐步跟踪变量，对编程题先写思路再写代码。
3. **把错误对应到章节。** 区分概念不清、代码执行过程判断错误、边界遗漏和时间不足。
4. **回到课件补漏，再重新做题。** 对存疑的代码进行实际编译验证，并结合教材或向老师请教。

## 🧭 04 · 推荐学习路线

### 平时学习：按章节理解，再动手练习

**章节课件 → 自己写小程序 → 整理笔记 → 找相关题目练习**

学习时可以给每章留一页个人总结：本章解决什么问题、常用写法是什么、自己在哪里出过错。

### 专题补漏：围绕具体问题查资料

**定位问题 → 查对应章节 → 做最小示例 → 回到原题验证**

例如，遇到指针问题时，可以结合第5章数组、第6章指针、第7章字符串和指针专题资料，画出变量、地址与指向关系，再运行代码检查判断。

### 考前复习：梳理框架，再做整卷

**复习课件与笔记 → 综合串讲 → 历年试题 → 错题回查 → 二次练习**

建议先选一份有参考答案的试卷检查当前水平，再根据错题分布安排复习；不同学期和转专业试卷按课程范围选做。
